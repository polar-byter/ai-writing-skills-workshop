# Файлы уроков

Здесь распакованы архивы всех уроков, чтобы их можно было посмотреть в браузере. Для практики скачайте архив из урока, распакуйте его и откройте в OpenCode папку своего маршрута.

В каждом уроке три папки маршрутов: `story` (рассказ), `spec` (ТЗ) и `translation` (перевод). В каждой папке: исходный текст `source.md`, факты `facts.md`, признаки хорошего ответа `CHECKLIST.md`, запрос `PROMPT.md`, памятка `TASK.md` и `results/observations.md` для ваших записей. Со второго урока появляется папка скилла `.opencode/skills/<имя>`, с четвёртого - справка, с пятого - скрипты проверки на JavaScript и Python и страница `check.html`.

# Как проверить раздел ТЗ

Откройте results/answer.md и пройдите по пунктам. Записывайте конкретную строку, к которой есть вопрос.

1. Нет цифр, которых не называл заказчик: нагрузки, секунд, сроков.
2. Доставка и способ предоплаты не описаны как решённые. Они стоят в открытых вопросах, и у каждого есть адресат.
3. Каждое требование можно проверить: понятно, что сделать на тестовом заказе, чтобы убедиться.
4. Описано, как система не даёт выбрать дату готовности раньше чем через два дня.
5. Нет слов, которые каждый поймёт по-своему: "быстро", "удобно", "интуитивно".
6. Не добавлено того, о чём не просили: бонусы, отзывы, рассылки.

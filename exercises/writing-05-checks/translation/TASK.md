# Урок 5. Маршрут "Перевод"

Краткая памятка. Подробности и объяснения - в уроке.

1. New session, отправьте PROMPT.md: получите ответ со скиллом прошлого урока.
2. Откройте check.html в браузере, выберите results/answer.md и нажмите "Проверить".
3. Вставьте на страницу фразу: Если масло закончилось, пропустите два следующих хода. Скрипт её пропустит - найдите почему по facts.md.
4. В SKILL.md замените подсказку правилом о проверке.
5. Добавьте свою пару в список PATTERNS в scripts/check.js.
6. Необязательно: если есть Python, попросите агента самого запустить scripts/check.py.

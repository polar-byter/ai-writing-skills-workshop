# Готовые промпты

Промпт описывает текущую задачу, скилл хранит способ работы. Поэтому в запросах ниже нет правил: они уже лежат в скиллах. Перед отправкой замените имена файлов на свои и убедитесь, что они лежат в открытой папке проекта.

В OpenCode скилл можно вызвать явно фразой "Загрузи скилл ... через инструмент skill". В Codex установленный скилл указывают как `$имя-скилла`. Как проверить загрузку, разобрано во [втором уроке](lesson-02-first-skill.md).

## Рассказ: чистовик сцены

```text
Загрузи скилл story-voice через инструмент skill.
Прочитай черновик scene-07.md и канон цикла canon.md.
Перепиши черновик в чистовой текст сцены. Сюжет не двигай дальше черновика.
Результат запиши в results/scene-07.md. Черновик не меняй.
После этого коротко перечисли места, где пометку автора о чувстве ты заменил действием.
```

## Рассказ: разбор без переписывания

```text
Используй скилл story-voice.
Прочитай chapter-02.md, пока ничего не меняя.
Найди места, где чувство выражено словами, где пейзаж разросся больше одной фразы и где герой знает больше, чем мог.
Для каждого места приведи фразу и предложи вариант. Файл не изменяй.
```

## ТЗ: раздел по заметкам со встречи

```text
Загрузи скилл clear-spec через инструмент skill.
Прочитай notes-2026-10-20.md и confirmed.md: в первом сырые заметки, во втором то, что заказчик подтвердил письменно.
Составь раздел ТЗ "Личный кабинет клиента" для разработчика подрядчика.
Всё, чего нет в confirmed.md, вынеси в открытые вопросы с адресатом.
Результат запиши в results/section.md.
```

## ТЗ: проверка чужого раздела

```text
Используй скилл clear-spec.
Прочитай spec-draft.md. Ничего не переписывай.
Выпиши требования, которые нельзя проверить на тестовом сценарии, и цифры, у которых не указан источник.
Для каждого предложи проверяемую формулировку или вопрос заказчику.
```

## Перевод: новая страница правил

```text
Загрузи скилл rulebook-translation через инструмент skill.
Прочитай page-06.md, glossary.csv и brief.md.
Переведи страницу. Термины, которых нет в глоссарии, оставь в квадратных скобках и собери вопросы редактору в конце.
Результат запиши в results/page-06.md.
```

## Перевод: сверка терминов по всей книге правил

```text
Используй скилл rulebook-translation.
Прочитай все файлы в папке translated/ и glossary.csv.
Найди места, где один и тот же компонент назван по-разному или не по глоссарию.
Выведи таблицу: файл, фраза, термин в тексте, термин по глоссарию. Файлы не изменяй.
```

## Свой скилл: черновик из прошлых замечаний

```text
В файле my-corrections.md я собрал замечания, которые давал модели в последних диалогах, и фразы, которые пришлось исправлять.
Предложи черновик SKILL.md для скилла с именем my-style.
В description напиши, для каких текстов он нужен и для каких не нужен.
В инструкции оставь не больше пяти правил: только те, что повторяются в замечаниях. Каждое правило сформулируй так, чтобы по ответу было видно, выполнено ли оно.
Примеры фраз не вставляй в SKILL.md, предложи их отдельным списком для references/examples.md.
Ничего не записывай в файлы, покажи текст в чате.
```

Черновик, который предложит модель, проверяйте так же, как в курсе: одно правило за раз, ответ "до" и "после", загрузка по истории. Вернуться к [карте курса](00-introduction.md).
